🎯 Filter Profiles
A personalized discovery system inspired by AllEvents-style preference management.

How Filter Profiles Work:

Logged-in customers can create and manage multiple filter profiles, each tuned to a specific country or city. This lets users maintain separate discovery preferences for different locations — for example, a "Trinidad" profile focused on events and services, and a "Barbados" profile focused on vacation stays and accommodation.

Each Filter Profile Includes:

📍 Location scope — country or city

📂 Category interests — which listing categories to prioritize (Events, Accommodation, Vacation, Services, Stores)

🎯 Keyword interests — specific themes, genres, or tags

💰 Price range — free, paid, or custom bracket

📅 Date preferences — upcoming, this weekend, this month, or custom

Managing Filter Profiles:

Create a new profile from the Profile section

Edit interests and preferences at any time

Switch between profiles to instantly change your discovery feed

Delete profiles no longer needed

Filtered Discovery:

Listings are surfaced based on the active filter profile

A "For You" or "Filtered" view displays listings matching current profile preferences

Users can toggle between all listings and filtered listings at any time



🤝 Collaborators
Multi-party listings made simple.

How Collaborators Work:

A Collaborator is listed as an Organization — not as an individual vendor (e.g., not as a DJ, caterer, or speaker)

Collaborators are discoverable and searchable alongside other organizations

Collaborator profiles display all listings they are linked to

Collaborators can be attached to any listing across categories

Under an Organization, listings are split into:

📦 Owned Listings — created and managed directly by the organization

🔗 Shared Listings / Collabs — listings co-created or co-managed with collaborators
